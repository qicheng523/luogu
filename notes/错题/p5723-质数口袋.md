## 当前写法
试除 `i` 从 2 到 `n`，用 `n % i == 0 && n / i > 1` 判断，复杂度 O(n) 而不是 O(√n)。

## 正确做法（二刷目标）
`for (i = 2; i * i <= n; i++)`，一旦 `n % i == 0` 立即返回 0；`n < 2` 返回 0。
