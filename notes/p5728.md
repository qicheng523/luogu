# P5728 旗鼓相当的对手（2026-11-26）
A1: 本题核心在于结构体的设置和如何让不同同学比较，如果不设置结构体，一个同学有4个变量，需要用很多数组储存信息； 让不同同学比较，需要用两个for循环嵌套，外循环表示选中的同学，内循环表示选中的对手，而外循环到最后一名同学时，他已经和其他同学都比较完了，所以外循环条件设置为 i < n - 1;而内循环不需要与自己比较，条件设置为 j = i + 1; j < n，四个条件同时满足才算作一对
A2: O (n ^2),本题有两个for循环嵌套在一起，内循环跑（n-i-1）次，外循环从0跑到n-2,$T(n)=\sum_{i=0}^{n-2}(n-i-1)=\frac{n(n-1)}{2}=O(n^2)$
A3: 输入规模X10，即输入10000时，时间复杂度为$1*10^8$接近一秒时限,此时数字不越界，int足够，输入为0时，输出为0,程序正常运行
