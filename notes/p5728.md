# P5728 旗鼓相当的对手（2026-11-26）
A1: 本题核心在于结构体的设置和如何让不同同学比较，如果不设置结构体，一个同学有4个变量，需要用很多数组储存信息； 让不同同学比较，需要用两个for循环嵌套，外循环表示选中的同学，内循环表示选中的对手，而外循环到最后一名同学时，他已经和其他同学都比较完了，所以外循环条件设置为 i < n - 1;而内循环不需要与自己比较，条件设置为 j = i + 1; j < n
A2: O (n * 2),本题有两个for循环嵌套在一起，且循环次数随输入的改变而改变
A3: 输入规模X10时，只读入3n + 1 ，(n为第一个数字的数值)；当输入过大时，数字越界，当
输入为0时，输出为0
