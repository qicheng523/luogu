# P1161 开灯（2026-11-26）
A1: 这一题需要看很多信息，算是向算法题过渡的第一步，1.一共有多少个路灯（数组要占用多大内存），说明中ti x ai的最大值不超过2000000,即数组至少设置为arr[2000001],2,因为ai的小数点一定有6位，而ai x ti很不方便，可以将ai x 1000000,,因为ai存进double时并不准确，当存入1.618034时，实际上是1.61803399999........ x1000000后会变成1.61803399998.....，比要求的数少一，可以新设一个longlong值A，A = ai  x 1000000 + 0.5，因为longlong会截断小数，所以会往前进一，得到我们要求的数
A2: 外层 n 次操作，第 i 次内层按 t_i 下，内层总次数为 Σt_i = T ≤ 2×10⁶；最后扫描 2×10⁶ 个灯位。总次数约 4×10⁶，时间复杂度 O(T + 2×10⁶)，即 O(T)。
A3: 当输入规模x10时，T * 10约为10^7次,可过,数组可能越界,需要扩到$2*10^7$,当输入足够大时longlong足够，当输入为0时，程序直接结束
